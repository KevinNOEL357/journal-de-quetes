# ⚔️ Journal de quêtes

Les tâches de la maison façon journal de quêtes de jeu vidéo : une roue de 8 thématiques,
des quêtes qui reviennent, de l'XP, des niveaux et des cœurs.

Appli web installable sur téléphone (PWA). Les données restent dans le téléphone (localStorage).

- `index.html` : le squelette de la page
- `style.css` : la déco
- `app.js` : le cerveau de l'appli
- `sw.js` : le service worker (mode hors connexion)
- `manifest.json` + `icones/` : pour l'installation sur téléphone
